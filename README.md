1. 이 저장소 위쪽 **Actions** 누르기
2. 왼쪽 **캠핑 빈자리 감시** 누르기
3. 오른쪽 **Run workflow** → "지금 빈자리 보기" 또는 "비 오는 날 추천" 고르고 초록 버튼
